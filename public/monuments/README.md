# Monument photos (optional)

Drop a real photo here named exactly `<monument-id>.jpg` and it will appear
automatically at the top of that monument's page. If no file is present, the
page falls back to the built-in annotated architecture illustration.

mehrangarh, umaid-bhawan, kumbhalgarh, chittorgarh, junagarh-fort,

sajjangarh, garh-palace-bundi, ranthambore-fort, bala-quila, ajmer-fort,
adhai-din-ka-jhonpra, chand-baori

Recommended: landscape orientation, ~1200×675px, optimised JPG.
